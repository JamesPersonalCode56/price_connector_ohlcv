# Chapter 7 - Configuration

Configuration is controlled by environment variables. Copy .env.example to .env and edit.

Core settings (examples):
- CONNECTOR_MAX_SYMBOL_PER_WS=50
- CONNECTOR_INACTIVITY_TIMEOUT=5.0
- CONNECTOR_STREAM_IDLE_TIMEOUT=30.0
- CONNECTOR_RECONNECT_DELAY=1.0

Queue and dedup settings (examples):
- CONNECTOR_CLOSED_QUEUE_MAXSIZE=1000
- CONNECTOR_OPEN_QUEUE_MAXSIZE=0 (0 = unbounded)
- CONNECTOR_DEDUPLICATION_WINDOW_SECONDS=120.0
- CONNECTOR_DEDUPLICATION_MAX_ENTRIES=10000

WebSocket server settings:
- CONNECTOR_WSS_HOST=127.0.0.1
- CONNECTOR_WSS_PORT=8765
- CONNECTOR_WSS_LOG_LEVEL=INFO
- CONNECTOR_WSS_SUBSCRIBE_TIMEOUT=10.0
